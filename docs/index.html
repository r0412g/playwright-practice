1. 登入表單 簡單

操作說明 所有元件都有 id，最適合入門練習。
  1. 帳號輸入 admin、密碼輸入 123456，按「登入」會顯示「登入成功」。
  2. 其他組合會顯示錯誤訊息；任一欄位空白會顯示「請輸入帳號與密碼」。
  3. 勾選「記住我」後登入，結果會多一行「已記住帳號」。
練習題
  1. 輸入 admin / 123456 登入，驗證 #login-result 顯示「登入成功，歡迎 admin」。
  2. 輸入錯誤密碼，驗證顯示「帳號或密碼錯誤」。
  3. 帳號或密碼留空按登入，驗證顯示「請輸入帳號與密碼」。
  4. 勾選「記住我」再登入，驗證結果多一行「已記住帳號」。

2. 各式輸入框 簡單

操作說明
  1. 在各欄位輸入資料後按「送出資料」，下方會以 JSON 顯示所有欄位值。
  2. Email 格式錯誤、年齡不在 1~120 之間時會出現紅字錯誤訊息。
  3. 「唯讀欄位」無法輸入，「停用欄位」無法聚焦，可練習驗證元件狀態（is_enabled()、readonly 屬性）。
  4. 「即時字數」欄位每輸入一個字，旁邊的計數會即時更新。
練習題
  1. 用 clear() 清空「姓名」的預設值後輸入新姓名，送出後驗證 JSON 中的姓名。
  2. Email 輸入 abc，驗證出現「Email 格式錯誤」。
  3. 年齡輸入 200，驗證出現「年齡必須介於 1 到 120」。
  4. 讀取唯讀欄位的 value 並驗證為 TEST-READONLY-001；驗證停用欄位 is_enabled() 為 false。
  5. 在「即時字數」輸入 5 個字，驗證計數顯示「5 / 20」。

5. 按鈕與點擊事件 中等

操作說明
  1. 「單擊」、「雙擊」、「右鍵」三個按鈕分別只回應對應的滑鼠動作（可練習 ActionChains / dblclick() / click(button='right')）。
  2. 「計數器」每按一次 +1，可練習點擊 N 次後驗證數字。
  3. 「3 秒後啟用」按鈕一開始是停用的，按「開始倒數」後 3 秒才能點擊，需使用明確等待。
  4. 「被遮住的按鈕」上面蓋了一層半透明遮罩，直接點擊會被攔截（ElementClickInterceptedException），請先按「移除遮罩」。
練習題
  1. 分別對三個按鈕執行單擊、雙擊、右鍵，驗證每次的結果文字。
  2. 點擊「計數器 +1」五次，驗證 #counter-value 為 5，再按歸零驗證為 0。
  3. 按「開始倒數」後用明確等待等到「3 秒後啟用」可點擊，點擊並驗證結果。
  4. 直接點「被遮住的按鈕」觀察例外，移除遮罩後再點擊並驗證結果。

6. 鍵盤事件 中等

操作說明
  1. 在輸入框中按任意鍵，下方會顯示按下的按鍵名稱（例如 Enter、Tab、ArrowUp）。
  2. 按 Ctrl + Enter（Mac 為 Cmd + Enter）會顯示「已送出：輸入框內容」。
  3. 自動完成：在「搜尋城市」輸入「台」，會出現建議清單，可用方向鍵 ↓ 移動並按 Enter 選取。
練習題
  1. 在按鍵偵測輸入框按 Enter，驗證顯示「你按下了：Enter」。
  2. 輸入文字後按 Ctrl + Enter，驗證顯示「已送出：」加上輸入內容。
  3. 在「搜尋城市」輸入「台」，按兩次 ↓ 再按 Enter，驗證選到「台中」。

    8. 動態表格 中等

    操作說明
    1. 在上方輸入姓名、部門、薪資後按「新增」，資料會加到表格最後一列。

    練習題

    3. 新增一筆資料，驗證最後一列的內容正確。
    4. 點擊「薪資」標題排序，驗證第一列為最低薪資；再點一次驗證為最高薪資。

    9. 瀏覽器對話框（alert / confirm / prompt） 中等

    操作說明
    1. 「Alert」跳出提示框，文字為「這是一個 Alert 提示框」。
    2. 「Confirm」按確定顯示「你按了確定」，按取消顯示「你按了取消」。
    3. 「Prompt」輸入文字後，結果會顯示「你輸入了：xxx」。
    4. 「延遲 Alert」會在 2 秒後才跳出。
    練習題
    1. 點擊 Alert，讀取對話框文字並驗證為「這是一個 Alert 提示框」後關閉（Selenium switch_to.alert / Playwright page.on('dialog')）。
    2. 點擊 Confirm 並接受，驗證顯示「你按了確定」；再點一次並取消，驗證顯示「你按了取消」。
    3. 點擊 Prompt 輸入你的名字，驗證顯示「你輸入了：」加上名字。
    4. 點擊「延遲 Alert」，用等待處理 2 秒後才出現的對話框。

    11. 等待與動態載入 中等

    14. 新分頁與新視窗 中等

    操作說明
    1. 「連結開新分頁」是 target="_blank" 的超連結，點擊後會開啟新分頁，新頁標題為「新分頁 - 練習頁面」。
    2. 「按鈕開新分頁」使用 JavaScript window.open() 開啟。
    3. 「開新視窗」會開啟一個指定大小的彈出視窗。
    4. 新頁面中有一個輸入框與按鈕，輸入文字並按「回傳給主頁」，主頁下方會收到該文字（新頁面會自動關閉）。

    3. 點擊「開新視窗」，驗證視窗數量變為 2，關閉後切回主頁。
    4. 點擊「延遲 2 秒開分頁」，等待新分頁載入完成再驗證標題。
    5. 點擊「在同一分頁開啟子頁面」，驗證網址含 page=sametab，再用上一頁回到主頁。

    15. 難定位元件 困難

    操作說明 這一區的元件刻意沒有 id，請練習 XPath、CSS Selector、文字定位、相對定位等技巧。
    1. A. 重複 class：三個按鈕 class 完全相同，請只點「確認」那顆（提示：依文字 //button[text()='確認']）。
    2. B. 動態 id：按鈕的 id 每次重新整理都會變（例如 btn-8271），請改用其他屬性定位（提示：[id^='btn-'] 或 data-action）。
    3. C. 商品卡片：找到「無線滑鼠」那張卡片，點擊同一張卡片裡的「加入購物車」（提示：先找名稱再往上找卡片，ancestor:: 或 Playwright 的 filter(has_text=...)）。
    4. D. 深層巢狀：多層 div 裡藏著一個連結，只有 class 名稱是隨機的。
    5. E. 相鄰元素：只知道標籤文字「員工編號」，請找到它右邊的輸入框並輸入資料（提示：following-sibling::）。
    6. F. 第 N 個項目：點擊清單中的第 3 個項目（提示：li:nth-child(3)）。
    7. G. 只有 aria-label 的圖示按鈕：沒有文字，只能用 aria-label 或 role 定位。
    練習題
    1. A：只點擊文字為「確認」的按鈕，驗證結果。
    2. B：不使用 id，定位「儲存」動態 id 按鈕並點擊；重新整理後確認你的定位方式仍然有效。
    3. C：點擊「無線滑鼠」卡片內的「加入購物車」，驗證按鈕變為「已加入 ✓」。
    4. D：定位深層連結並點擊，驗證結果。
    5. E：在「員工編號」右邊的輸入框輸入 E001，按「讀取 E 區輸入值」驗證。
    6. F：點擊清單第 3 個項目，驗證結果為「項目三」。
    7. G：用 aria-label 點擊「編輯」圖示按鈕，驗證結果。

    16. 拖曳（Drag & Drop） 困難

    操作說明
    1. 將黃色項目拖到右側「目標區」，目標區會列出已放入的項目。
    2. 下方清單可拖曳排序，排序後結果會顯示目前順序。
    3. 使用 HTML5 原生拖曳 API，Selenium 的 drag_and_drop 在某些版本可能無效，可改用 Playwright drag_to() 或 JavaScript 模擬。
    練習題

    17. iframe 內嵌框架 困難

    操作說明 下方框架是一個獨立的文件，直接在主頁找 iframe 裡的元素會找不到，必須先切換進 iframe。
    1. 切換到 #practice-iframe（或 name="practiceFrame"）。
    2. 在框架內的 #iframe-input 輸入文字，按「送出」，框架內會顯示結果。
    3. 框架內還有一個巢狀 iframe（#inner-iframe），裡面有一顆按鈕，需要再切換一層。
    4. 操作完記得切回主頁（switch_to.default_content()）。
    練習題
    1. 切換到 #practice-iframe，在 #iframe-input 輸入文字並送出，驗證 #iframe-result。
    2. 再切換進 #inner-iframe，點擊「內層按鈕」並驗證結果。
    3. 切回主頁，驗證可以再次操作主頁上的元素（例如讀取 #page-title）。

    18. Shadow DOM 困難

    操作說明 下方元件在 Shadow DOM 中，一般 XPath 無法穿透。
    1. 宿主元素為 #shadow-host（open 模式）。
    2. Selenium 4 可用 host.shadow_root.find_element(By.CSS_SELECTOR, '#shadow-input')；Playwright 的 CSS 定位器預設可穿透。
    3. 在 Shadow DOM 輸入框輸入文字並按按鈕，下方會顯示結果。
    練習題
    1. 定位 #shadow-host 的 shadow root，在 #shadow-input 輸入文字。
    2. 點擊 Shadow DOM 中的「確認」按鈕，驗證 #shadow-result 顯示「Shadow DOM 收到：」加上輸入內容。
    3. 嘗試直接用一般 XPath 找 #shadow-input，觀察為什麼找不到。
